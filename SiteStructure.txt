Notes
-----
1. Every page in /services references shared assets with a "../"
   prefix (e.g. "../css/style.css", "../images/HCALogo.jpg") and links
   back to the home page as "../index.html". index.html itself uses
   plain paths ("css/style.css", "services/tax-filing.html"). Keep this
   pattern if you add further pages.

2. Optional further tidy-up: move css/, js/, and images/ into a single
   assets/ folder (assets/css, assets/js, assets/images) and update the
   <link>/<script>/<img> paths in every HTML file accordingly. Not
   required — the current flat top-level folders work as-is.

3. Third-party libraries (Bootstrap 5.3, Bootstrap Icons 1.11) load
   from CDN in every page's <head>. No local vendor folder is needed
   unless an offline-capable build is wanted later.

4. Keep the floating WhatsApp button markup and the
   ".hca-whatsapp-fab" CSS rule untouched when moving files — its
   fixed bottom-right position rule depends on this class staying in
   css/style.css.

5. The contact form on index.html is currently hidden (class="d-none"
   on the <form> tag) at the client's request. Remove that class when
   ready to re-enable it — the mailto: action and validation are
   already wired up.
